# Eitangoze — 英語だけの単語・熟語アプリ

見出し 18,575 項目・語義 70,358 の語彙データベースを、**再配布が認められている公開データだけから
機械的に組み上げて**同梱した Android アプリ（Kotlin / Jetpack Compose）。
通信は一切行わず、全部が端末内の SQLite にあります。

市販の単語帳は使っていません。生成手順は `tools/` に全部あり、誰でも同じものを作れます
（[tools/SOURCES.md](tools/SOURCES.md)）。

## 辞書ページが本体

無料の英単語アプリはたいてい「見出し語 → 訳語」の1行しか持っていません。
このアプリの1語のページには、収録データがそのまま出ます。

### 意味の使われ方（他にない部分）

辞書は語義を**並べる**だけで、どれが本命かは書いていません。
このアプリは語義ごとの比率を帯で出します。

```
run  動  /rʌn/  A1  NGSL

意味の使われ方
████████████████░░░░░░░░░░░░
■ 62%  走る、駆ける
■ 22%  逃げる、脱出する
■ 10%  広がる、伸びる
■  6%  経営する
語義タグ付きコーパス（SemCor）での出現比率
```

根拠は [SemCor](https://www.sketchengine.eu/semcor-annotated-corpus/)（人手で語義タグを付けた英語コーパス）の実測値です。
編集者の主観ではありません。2,557 語で比率が出ます。

#### 訳が重なる語義は、1つの記憶として扱う

WordNet は語義を、日本語訳が追いつけないほど細かく割ります。比率が出る 3,743 語のうち
**1,572 語（42%）で、1位と2位の日本語訳が同じ語**でした。そのまま出すと帯は
「為す 62% ／ 為す 32%」と読め、文脈判別は——誤答選択肢をその語**自身の別の語義**から作るので
——同じ答えが2つ並んだ問題になります。

なので **語義どうしが日本語訳を1つでも共有していたら、それは1つの記憶として束ねます。**
頻度は足し、訳とラベルは寄せ、最初の行が代表になります。

```
make   前: 為す 35% ／ 為す 32% ／ 生じる 17%
       後: 為す、やる、致す 73% ／ 生じる、産む、生みだす 20%

time   前: 時 37% ／ 時 27% ／ 時 19% ／ 時 7%
       後: （日本語では1つの意味なので、帯を出さない）
```

このアプリが教えようとしている区別は、この規則では消えません。**本当に違う意味は、
日本語訳も違う**からです——`spare` は 見逃す ／ 放棄 のまま分かれています。

束ねるのは読み出しのときで、データベースの行は削っていません。規則を変えたくなったときに
作り直さずに済むようにしてあります。

### 語の分解と、接辞の格子

語根は**意味**、接辞は**演算子**として分けています。1語のページの最上段に分解が出ます。

```
introduction   名  /ˌɪntrəˈdʌkʃən/  B1

┌──────────┬──────────┬────────────┐
│  intro-  │   duc    │   -tion    │
│   内へ    │   導く    │  〜すること  │
└──────────┴──────────┴────────────┘
```

接辞を押すと**格子**が開きます。ここが紙の語源本と違うところです。

```
-tion   接尾辞   〜すること、〜の結果            155語

  attend      attention     注意
  produce     production    生産
  describe    description   記述
  introduce   introduction  紹介
  reduce      reduction     減少
  receive     reception     受理
  prescribe   prescription  処方
```

左の列を押すと**軸が入れ替わり**、こんどは `describe` を固定した格子になります。
紙は1次元なので「語根ごとのリスト」しか持てず、**同じ接辞が別の語根でも同じ働きをする**
という一番効く気づきが出てきません。格子はそこを見せるためのものです。

まだ学習していない語は訳を伏せて `░░░░` で出し、「あと N 語でこの系列が埋まります」と
表示します。推測できるようになるのが目的なので、先に答えを見せません。

分け方は **Wiktionary の語源記述そのまま**で、綴りからの推測はしていません。
綴りを削る規則を書くと `region` が re- ＋ gion になり、嘘を教えることになるからです。
そのぶんカバーは 2,525 語（見出しの 13%）にとどまります。

### 同語根ファミリー

```
同語根 duc
  ラテン語 ēducātiō「a breeding, bringing up」
  intro**duc**e    導入する
  re**duc**e       減らす
  con**duc**t      行う、指揮する
  edu**c**ation    教育
  …
```

Wiktionary の印欧祖語の語根で束ね、**実際に綴りとして見える部分**だけを家族の条件にしています。
`*per-` のように fear と parent まで巻き込む根は、共通の綴りがないので採用しません。
接頭辞（pro-, con-, inter-）が共通しているだけの「家族」も除外します。

### そのほか1ページに載るもの

- 語義ごとの**日本語訳・英英定義・日本語定義・例文**（語義に紐づく）
- **語法タグを日本語で**（他動詞 / 不可算 / かたい語 / 比喩 / 限定用法 …）
- **コロケーションをコーパス出現回数つきで**（`make a mistake` 111回）
- 発音記号・活用形・CEFR レベル・NGSL / NAWL 収録の別
- 対訳例文、類義・対義・派生・混同注意

## 読む英文は、最初から入っている

英文を貼る必要はありません。**13ジャンル**の読解用パッセージ（各 700〜900 語、
京大の長文と同じ尺）が同梱されていて、**全文があらかじめ構文解析済み**です。

| | |
| --- | --- |
| パッセージ | **4,126 本 / 327 万語**（各 400〜1,100 語） |
| ジャンル | 自然科学 / 医学・脳科学 / 技術・AI / 環境 / 経済 / 歴史・文明論 / 哲学 / 言語・教育 / 芸術 / 社会・政治 / 時事 / 物語・文学 / 随筆・演説 / やさしい英語 |
| レベル | B1 131 / B2 1,625 / C1 2,043 / C2 326 |
| 出典 | English Wikipedia・Wikinews・Project Gutenberg・PubMed Central のオープンアクセス集合（[tools/SOURCES.md](tools/SOURCES.md)） |
| 構文 | **89,047 文を解析済み**。うち 53,651 文（60%）は2つのパーサが一致し、**174,896 か所**が畳めます。残り 1,301 本は読めますが、まだ畳めません |

解析は端末では行いません。パッセージはビルド時に確定しているので、**1度だけ解析して
木ごと同梱**します。スマホにパーサは載りませんし、待ち時間も出ません。

パーサの精度はニュース英文で語られる数字で、**難しい学術英文ほど落ちます**。
設計メモに例として書いた文を、実際に小さいモデルが誤りました。

```
Although the evidence that had been gathered over the preceding decades
suggested otherwise, most researchers continued to assume that ...

  en_core_web_sm    evidence → continued の主語、suggested → decades の修飾   誤り
  en_core_web_trf   evidence → suggested の主語、suggested → 副詞節          正しい
```

そこで **transformer が解析し、小さいモデルが照合**します。照合は文単位ではなく
**畳む部分ごと**です（2つのパーサは前置詞の係り先や句読点の扱いで年中食い違い、
そのどれも節の切れ目を動かさないため）。一致しなかった文は普通に読めますが、
畳む操作は出しません。

## 読解カバー率と忘却プレビュー

英文を貼る（あるいは他アプリから共有する）と、あなたの記憶の予測でその英文を描き直します。
時間を進めると、何もしなかった場合に読めなくなる語から順に消えていきます。
**いま読めるかは読めば分かりますが、3か月後に読めるかは読んでも分かりません。**

同時に次を出します。

| 出るもの | 意味 |
| --- | --- |
| **読める率** | 走行語数のうち、あなたが思い出せると予測される語の割合 |
| **98% まであと N 語** | 出現回数の多い順に、あと何語覚えれば辞書なしで読めるか |
| 内訳 | 覚えている / 学習中 / 未学習 / 辞書外 の比率 |
| 語彙レベル | 95% をカバーするのに必要な CEFR レベル |
| この英文の上限 | 全部覚えても何％か（残りは固有名詞など） |

判定の中身は正直に作ってあります。

- **「読める」は、復習段階（REVIEW）に入っていて、かつ予測想起率が 80% 以上の語だけ。**
  さっき間違えた語は、FSRS 上の直後の想起確率が 1.0 でも「読める」に数えません。
- **機能語（the / is / of など 320 語）は既知として数えます。** これらは訳語を持たないため
  本来なら収録対象外ですが、落とすと普通の英文の 15% が「辞書外」になり、カバー率が
  98% に届かなくなります。出題には一切使いません。
- **「すでに知っている層」を申告できます。** 初回に `to` や `have` まで未学習と数えると
  数字が実態と合わないためです。申告は出題には影響せず、実際に答えた語はその結果が優先されます。
- **句動詞は 1 語として数えます。** `look up to` を look / up / to の 3 語として数えると、
  3 語とも知っている人が「読める」と判定されてしまいます。

## なぜこの作りなのか

京大英語は[長文2題（下線部和訳2＋内容説明1）＋和文英訳＋自由英作文](https://www.zkai.co.jp/kyodai-exam/bunseki/eigo/)で、
語彙レベル自体は標準〜やや難です。差がつくのは語数ではなく、

- **その文でどの意味か**を決められるか（下線部和訳）
- **日本語から英語を作れる**か（和文英訳・自由英作文）
- **語法・コロケーション**を外さないか（減点されるのはここ）

の3点です。だから「単語 → 訳語」を1万語積むのではなく、**同じ語について違う問い方をする**設計にしました。

### 2. 意味は語義ごとに持つ

`spare` は「予備の」「惜しむ」「（危害を）加えない」が別々の記憶です。
このアプリは語義を独立した行として持ち、それぞれに日本語訳・英英定義・例文・語法ラベルが付きます。

語義の並び順は **SemCor（人手で語義タグを付けた英語コーパス）の出現回数**で決めています。
「どの意味から覚えるべきか」に根拠がある、という意味です。よく出る意味には「よく出る」と表示されます。

### 3. 文脈判別

例文を見せて、**その語自身の他の意味**を選択肢にして、どの意味かを選ばせます。

```
この文の spare はどの意味？
  He asked if they could spare one of their horses.

  ① 予備の、余分な
  ② 惜しむ、割く            ← 正解
  ③ 危害を加えない、見逃す
```

選択肢が他人の語の訳語なら、消去法で当たってしまいます。**同じ語の別の意味**だから、
意味を知っているかどうかがそのまま出ます。下線部和訳で効くのはこの力です。

### 4. 出題の種類（それぞれ別々に復習日を持つ）

| 種類 | 問い方 |
| --- | --- |
| 英→和 | 語を見て意味を選ぶ。誤答は**同じ難度帯の語**の訳語から作る |
| 文脈判別 | 例文の中でどの意味かを選ぶ（上記） |
| 和→英（入力） | 意味から語を**書く**。頭文字と字数のヒント付き |
| 例文穴埋め | 対訳つきの例文の空所を埋める。活用形でも原形でも正解 |
| コロケーション | `___ a decision` → make。**意味からは予測できない側**を空所にする |
| 句動詞の前置詞 | `put ___` ＋「延期する」→ off |
| 語源→語 | ラテン語 `ubīque`「everywhere」＋「遍在する」→ ubiquitous |
| 和文英訳 | 日本語文を英訳して提出 → 模範解答と並べて**自己採点**（既定はオフ） |

「英→和は分かるのに和→英が出てこない」を別の記憶として個別にスケジュールするためです。

採点は表記ゆれを吸収します（大文字小文字、前置きの `to / a / the`、句読点）。
**1文字違いは「不正解」ではなく「惜しい」**として区別し、評価ボタンの推奨に反映します。

和文英訳だけは自動採点しません。同じ日本語に正しい英文は何通りもあり、文字列比較では
正解の大半を不正解にしてしまうからです。模範解答を出したうえで、押さえるべき点を
1項目ずつチェックする自己採点方式にしています。

### 5. 試験日から逆算する

設定で試験日を入れると、スケジュールの基準が「今日が期限か」から
**「その日に覚えていられるか」**に変わります。

- ホームに、試験日時点の予測定着率と、目標を下回る見込みのカード枚数が出ます
- 「試験日に弱い順で復習する」で、**その日いちばん弱くなっているカードから**出題します
- 残り60日を切ると、目標定着率を自動で 97% まで少しずつ引き上げて間隔を詰めます

## 復習アルゴリズム

[FSRS-6](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm)
（Free Spaced Repetition Scheduler）を実装しています。カードごとに安定性 S（忘れにくさ）と
難易度 D を推定し、想起確率が**目標定着率**（既定 90%）まで下がる日を次回の出題日とします。
数式は [py-fsrs](https://github.com/open-spaced-repetition/py-fsrs) のリファレンス実装に照合済みで、
`app/src/test/java/com/eitangoze/FsrsTest.kt` が具体的な数値で検証しています。

そのほかの学習設計:

- **新規カードの分散** — 新規は先頭に固めず、復習の間に等間隔で挿入します
- **兄弟カードの分散** — 同じ語の別の問い方が連続して出ないよう並べ替えます
- **1日の新規上限**（デッキごと）— 翌日以降の復習が雪だるま式に増えるのを防ぎます
- 「もう一度」を押したカードはその日のうちに戻ってきます

## 手持ちの単語帳を使う

「取り込み」から、1行1語（または TSV/CSV の1列目）で見出し語を貼ると、
収録データと照合して**その順番で**出題します。意味・例文・語法はこのアプリのデータを使うので、
貼るのは見出し語だけで足ります（市販単語帳の訳文を書き写す必要はありません）。

## 語彙データベースの作り方

`tools/` のスクリプトが、公開データから `app/src/main/assets/content.dbz` を生成します。

```bash
tools/fetch.sh                # 素材をダウンロード（計 3.5 GB, tools/raw/ 以下）
python3 tools/step1_wordlists.py       # CEFR-J / NGSL / NAWL / TSL / 頻度を統合
python3 tools/step2_wiktionary.py      # Wiktionary から語義・例文・日本語訳・語法を抽出
python3 tools/step3_wordnet.py         # 日本語 WordNet から語義単位の日本語
python3 tools/step4_tatoeba.py         # 英日対訳文
python3 tools/step5_corpus.py          # コロケーション計数用のコーパス
python3 tools/step6_japanese_common.py # 訳語の並べ替え用の常用語判定
python3 tools/build_db.py              # 統合して SQLite を生成
```

生成物はリポジトリにコミットされているので、**アプリをビルドするだけならこの手順は不要**です。

### 設計上の判断

いくつかは「入れない」という判断をしています。理由は [tools/SOURCES.md](tools/SOURCES.md) に書きました。

- **日本語訳がない語は収録しない。** Wiktionary にも日本語 WordNet にも訳がない語が
  約 3,500 項目ありました。答えられない問題を作っても意味がないので落としています。
- **和英辞典（JMdict）の逆引きはしない。** 試すと `adaptable`→「滑脱」、`addicted`→「どっぷり」の
  ように、日本語としては正しくても見出し語の訳としては使えないものが出ます。そのぶん
  `bravely` `coastal` のような派生語が約 400 語落ちますが、**誤った訳が入るほうが害が大きい**と判断しました。
  JMdict は「どの日本語が常用語か」の判定（訳語の並べ替え）にだけ使っています。
- **熟語は 1,009 項目にとどめた。** Wiktionary には 12,000 以上の熟語がありますが、
  現代のコーパスに2回以上現れ、かつ**主たる意味が Wiktionary 自身に裏付けられている**ものだけを採りました。
  市販の熟語帳（『速読英熟語』で 811 項目）と同じ規模です。
- **音声は同梱しない。** Tatoeba の音声は話者ごとにライセンスが異なるためです。

## APK をつくる

```bash
./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease      # app/build/outputs/apk/release/app-release.apk
./gradlew testDebugUnitTest    # ユニットテスト
```

`git push` すると GitHub Actions（`.github/workflows/android.yml`）が同じものをビルドし、
APK を artifact として添付します。

### リリースする

`.github/release.txt` にバージョン（例: `v1.0`）を書いて push すると、
`.github/workflows/release.yml` がテストと release ビルドを走らせ、
**タグと GitHub Release を作って APK を添付**します。
リリースノートは `.github/release-notes/<タグ>.md` を置けばそれが使われます。

**端末へのインストール**: APK を端末に移し、ファイルアプリから開きます。
初回は「不明なアプリのインストール」の許可が必要です。

`assembleRelease` は利便のため debug キーで署名しています。ストア配布や長期運用をする場合は
自前のキーストアに差し替えてください。
